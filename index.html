One caution

        
The server uses the Supabase service_role
          key, which bypasses row-level security. That is correct for a server on your own
          machine and wrong everywhere else — it must never appear in this page, in the
          repo, or in a chat. Board content is one JSON row, so avoid editing a board here
          while Claude is writing to it.
